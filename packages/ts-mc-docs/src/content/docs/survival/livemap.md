title: LiveMap
description: Interactive browser map of the server's worlds.
---

The [LiveMap](https://bluemap.ts-mc.net/) is a web-based tool that shows
an interactive map of the worlds on the server. It can best be described
as Google Maps for Minecraft.

Each [world](/survival/worlds/) has its own map:

| Map                    | World                                               |
| ---------------------- | --------------------------------------------------- |
| 2026 Map               | Frontier, the main survival world (the default map) |
| 2015 Map (/spawn)      | Spawn, the restored Main Map 1                      |
| 2016 Map               | The restored Main Map 2                             |
| Skylands, Wilds, Peaks | The worlds of the same names                        |
| Creative               | The creative plot world                             |
| Nether, The End        | The survival Nether and End                         |

A red line marks each world's border; turn it off under **World border** in the
map's marker menu. Minigame arenas are not on the map.

The creative map is [creative](https://bluemap.ts-mc.net/#creative). How to
enter, claim, name, trust, and download a plot is on the [creative](/creative/)
page.
