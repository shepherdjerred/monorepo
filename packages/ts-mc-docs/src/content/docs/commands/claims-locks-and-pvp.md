---
title: Claims, locks, and PvP commands
description: Protect land and manage access.
---

| Command                                                                                                                           | Action                                                 |
| --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| `/claim`, `/unclaim`, `/claim info`                                                                                               | Claim or unclaim the current chunk, or inspect it.     |
| `/claim personal`, `/claim shared`                                                                                                | Choose personal or shared camp claim access.           |
| `/claim trust <player>`, `/claim untrust <player>`                                                                                | Change access to a claim.                              |
| `/claim flag <flag> <true\|false>`                                                                                                | Change a claim setting.                                |
| `/lock`, `/unlock`, `/lock info`                                                                                                  | Lock, unlock, or inspect a container or door.          |
| `/lock trust <player>`, `/lock trust <player> manage`, `/lock untrust <player>`                                                   | Grant use or management access, or remove access.      |
| `/lock share on`, `/lock share off`                                                                                               | Change claim sharing for a lock.                       |
| `/lock redstone on`, `/lock redstone off`                                                                                         | Allow or block redstone access.                        |
| `/lock private`, `/lock public`, `/lock donation`, `/lock supply`, `/lock display`, `/lock password <password>`                   | Set the lock type.                                     |
| `/lock hopper on`, `/lock hopper off`                                                                                             | Allow or block hopper transfers.                       |
| `/lock hopperin on`, `/lock hopperin off`, `/lock hopperout on`, `/lock hopperout off`                                            | Control transfers in or out separately.                |
| `/lock golem on`, `/lock golem off`, `/lock magnet on`, `/lock magnet off`                                                        | Change golem and magnet options.                       |
| `/lock autoclose on`, `/lock autoclose off`, `/lock explosions on`, `/lock explosions off`, `/lock exempt on`, `/lock exempt off` | Change lock options.                                   |
| `/lock mode persist`, `/lock mode nolock`, `/lock mode droptransfer`, `/lock mode quiet`                                          | Toggle your lock modes.                                |
| `/cprivate`, `/cinfo`, `/cremove`, `/cmodify`                                                                                     | Shortcuts to lock, inspect, remove, or inspect a lock. |
| `/pvp`, `/pvp status`, `/pvp on`, `/pvp off`                                                                                      | Check or change your PvP preference.                   |

Look at the block when using lock commands. Claim and lock changes require the appropriate ownership or role.

See [claim settings](/homes/claim-settings/), [managing locks](/homes/managing-locks/), and [PvP and safety](/survival/pvp/).
