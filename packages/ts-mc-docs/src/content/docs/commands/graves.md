---
title: Grave commands
description: Find your graves and return after death.
---

| Command        | Action                                           |
| -------------- | ------------------------------------------------ |
| `/graves`      | Find your graves.                                |
| `/back`        | Return to your previous location when available. |
| `/tpinfo back` | Check details for returning.                     |

See [graves](/survival/graves/) and [grave recovery](/survival/advanced/grave-recovery/).
