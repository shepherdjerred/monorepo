description: Find help with travel, belongings, claims, quests, and communication.

Start with the guide for the problem you are trying to solve:

| Problem                                       | Where to look                                                                                 |
| --------------------------------------------- | --------------------------------------------------------------------------------------------- |
| I cannot travel or teleport                   | [Travel](/survival/travel/) and [teleport requests](/survival/advanced/teleport-requests/)    |
| I died or cannot recover my belongings        | [Graves](/survival/graves/) and [grave recovery](/survival/advanced/grave-recovery/)          |
| I cannot build or share land                  | [Camps and towns](/homes/camps-and-towns/) and [sharing land](/homes/sharing-land/)           |
| A quest is not progressing                    | [Quest offers and hand-ins](/adventures/quest-progress/#if-progress-does-not-advance)         |
| I cannot find a message or collect a delivery | [Chat and mail](/community/chat-and-mail/)                                                    |
| I need help with a creative plot              | [Manage creative plots](/creative-plots/) and [plot maintenance](/creative-plot-maintenance/) |

If you still need help, use `/ticket <what happened>` in game or the linked [Discord](/discord/) channel. Include the location and what you tried.
