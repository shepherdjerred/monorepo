---
title: Creative commands
description: Visit and manage creative plots.
---

| Command                                                                          | Action                                             |
| -------------------------------------------------------------------------------- | -------------------------------------------------- |
| `/creative`, `/creative leave`                                                   | Enter or leave creative.                           |
| `/creative claim`, `/creative auto`                                              | Claim a plot or find one automatically.            |
| `/creative home [plot]`, `/creative tp <plot>`                                   | Visit your plot or a specified plot.               |
| `/creative info`, `/creative list`                                               | Inspect or list plots.                             |
| `/creative name <name>`, `/creative desc <description>`                          | Set a plot's name or description.                  |
| `/creative flag <name> <value>`                                                  | Set a plot flag.                                   |
| `/creative floor <name>`, `/creative wall <name>`, `/creative biome <name>`      | Change the plot's floor, wall, or biome.           |
| `/creative member <player>`, `/creative unmember <player>`                       | Manage plot members.                               |
| `/creative trust <player>`, `/creative untrust <player>`                         | Manage trusted players.                            |
| `/creative deny <player>`, `/creative undeny <player>`                           | Manage denied players.                             |
| `/creative save <name>`, `/creative load`, `/creative paste <name>`              | Manage and paste plot copies.                      |
| `/creative clear`, `/creative clear confirm`                                     | Request and confirm clearing a plot.               |
| `/creative reset`, `/creative unclaim`                                           | Reset plot settings or give up a plot.             |
| `/creative merge <plot>`, `/creative unlink`                                     | Merge adjacent plots or unlink them.               |
| `/creative rate <score>`, `/creative comment <text>`, `/creative comment delete` | Rate or comment on a plot, or delete your comment. |
| `/creative download`                                                             | Download a plot copy.                              |

Plot commands may require you to be on a plot and have the appropriate role.

See [creative plots](/creative-plots/), [plot maintenance](/creative-plot-maintenance/), and [plot copies](/creative-plot-copies/).
