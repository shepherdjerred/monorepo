# Android store artwork

`icon-512.png` is a 512-pixel PNG derived from the canonical
[`icon-ios-1024.svg`](../../tasks-for-obsidian/branding/Facet/source/icon-ios-1024.svg)
using Resvg 2.6.2 at width 512. The source artwork remains unchanged.

The adaptive launcher uses the same color geometry and the canonical
[`icon-mono-line.svg`](../../tasks-for-obsidian/branding/Facet/source/icon-mono-line.svg)
for themed icons. Its uniform inset fits Android's adaptive icon canvas.
These assets do not establish a registered Google Play identity.
