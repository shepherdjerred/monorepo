---
title: Skills, tracks, spells, and shards commands
description: Inspect and use progression systems.
---

| Command                                                                                                                     | Action                                                                              |
| --------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `/skills`, `/skills <name>`, `/skills top`                                                                                  | View skills, a skill's details, or the leaderboard. `/mcmmo` is an alias.           |
| `/perks`, `/perks info <track>`, `/perks buy <track>`                                                                       | View tracks, inspect one, or buy its next level. Repeat the buy command to confirm. |
| `/spells`, `/spells info <spell>`, `/spells bind <spell>`                                                                   | View, inspect, or bind spells.                                                      |
| `/shards`, `/shards info`                                                                                                   | Show shard help or inspect the item in your hand.                                   |
| `/beginnersluck`                                                                                                            | Check your beginner protection.                                                     |
| `/stargate network create public <name>`, `/stargate network create private <name>`, `/stargate network create town <name>` | Create a Stargate network.                                                          |
| `/stargate network invite <network> <player>`, `/stargate network uninvite <network> <player>`                              | Manage invitations to your private network.                                         |
| `/stargate remove <network> <gate>`                                                                                         | Remove an accessible Stargate after its portal closes.                              |

Creating a Stargate network requires Mechanic III and access; a town network also requires town membership.

See [skills](/progression/skills/), [tracks](/progression/tracks/), [spells](/progression/spells/), and [shards](/progression/shards/).
