# dotfiles

Chezmoi source tree for dotfiles, shell configuration, macOS defaults, and
machine bootstrap (`install.sh`, `install_macos.sh`), plus a small Bun scripts
package (`bun run test` covers `scripts/`). When changing any config file that
chezmoi manages, edit both the live copy and this source tree — see the
[dual-edit rule](AGENTS.md#chezmoi-dotfiles--dual-edit-rule) in
[AGENTS.md](AGENTS.md).
