---
title: Windows setup
description: Set up Windows amd64 clients for MW2 and Black Ops I, II, and III crossplay.
---

Use this page on **Windows x64 (amd64)**. Install the client for your game using
its Windows walkthrough below. Once your local game works, continue to
[Play together](/docs/crossplay/play-together/).

## Before installing

- Own the game and the maps the group will use.
- Finish game downloads and extraction before installing the client.
- Pick a base-game map for the first session.
- Read the [compatibility reference](/docs/crossplay/) before planning a mixed-platform session. BO1/2 on Mac remain experimental; actual crossplay is untested here.

## Modern Warfare 2

Install **IW4x** for the original **Modern Warfare 2 (2009) Multiplayer** entry.
Use the current Steam game files and current IW4x launcher.

[Follow the Windows MW2 walkthrough](/docs/iw4/) for game-folder selection,
launcher setup, and updates. Its main path uses the group ZIP; the Steam
installation alternative is included on the same page.

**Ready to join:** reach the IW4x multiplayer menu and open the server browser.

## Black Ops I

Install **Plutonium T5** and select the Black Ops game folder. Configure both
the **T5 Singleplayer** entry for Zombies and **T5 Multiplayer** for MP.

[Follow the Windows Black Ops walkthrough](/docs/t5/) for downloads, launcher
login, folder selection, both modes, and screenshots.

**Ready to join:** load a solo Zombies map and confirm the multiplayer menu opens.

## Black Ops II

Install **Plutonium T6** and configure **T6 Zombies** and **T6 Multiplayer** with
the same Black Ops II game folder.

[Follow the Windows Black Ops II walkthrough](/docs/t6/) for downloads, launcher
setup, both modes, and screenshots.

**Ready to join:** load a solo Zombies map and confirm the multiplayer menu opens.

## Black Ops III

Install **Steam Black Ops III + T7Patch**. The group's Steam crossplay route uses
T7Patch, with a shared **Network Password**. BOIII compatibility with this route
is unverified.

[Follow the BO3 Steam crossplay walkthrough](/docs/crossplay/windows/bo3/) for Steam installation,
the Windows patch download, password setup, and screenshots.

The separate [Windows BO3 ZIP walkthrough](/docs/t7/) uses BOIII and is not the
client route for this crossplay setup.

**Ready to join:** load a base map with T7Patch running. Agree on a game-specific
group passcode before using the [shared joining steps](/docs/crossplay/play-together/#black-ops-iii).
