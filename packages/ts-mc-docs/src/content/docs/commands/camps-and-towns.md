---
title: Camps and towns commands
description: Create and manage a camp or town.
---

| Command                                                              | Action                                                            |
| -------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `/camp`, `/camp help`, `/camp create`                                | Check your camp, see help, or start a camp.                       |
| `/camp invite <player>`, `/camp join <owner>`                        | Invite someone or join a camp.                                    |
| `/camp leave`, `/camp kick <player>`                                 | Leave a camp or remove a member.                                  |
| `/camp graduate <name>`                                              | Graduate an eligible camp into a town.                            |
| `/camp delete`, `/camp delete delete`                                | See the deletion prompt, then confirm deletion of your camp.      |
| `/town`, `/town info`, `/town info <name>`                           | View your town or inspect a named town.                           |
| `/town create <name>`, `/town list [page]`                           | Create a town or browse the directory.                            |
| `/town invite <player>`, `/town accept <town>`, `/town deny <town>`  | Manage invitations.                                               |
| `/town leave`, `/town kick <player>`                                 | Leave or remove a member.                                         |
| `/town promote <player>`, `/town demote <player>`                    | Change a member's role.                                           |
| `/town balance`, `/town deposit <amount>`, `/town withdraw <amount>` | Check or manage town funds.                                       |
| `/town transfer <player>`, `/town transfer confirm`                  | Transfer ownership with confirmation.                             |
| `/town rename <name>`                                                | Rename your town.                                                 |
| `/town delete`, `/town delete <name>`                                | See the deletion prompt, then confirm by typing your town's name. |

Creating a town or graduating a camp requires Governor I. Some actions require the right role. See [camps and towns](/homes/camps-and-towns/).
