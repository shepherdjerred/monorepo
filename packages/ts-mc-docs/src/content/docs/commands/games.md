---
title: Arena and Search and Destroy commands
description: Join, play, and spectate minigames.
---

| Command                                                           | Action                                                                         |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `/arena`, `/arena list`, `/arena join <arena>`                    | Show usage, find, or join a Mob Arena.                                         |
| `/arena class <class>`, `/arena ready`, `/arena leave`            | Choose a class, ready up, or leave.                                            |
| `/arena spec <arena>`, `/arena top <arena>`                       | Spectate or view a leaderboard.                                                |
| `/survival tips on`, `/survival tips off`, `/survival tips reset` | Change or reset survival arena tips.                                           |
| `/survival guide`, `/survival classes`, `/survival upgrades`      | Open the survival arena guide, classes, or upgrades.                           |
| `/survival ability`, `/survival status`                           | Use your class ability or check your status.                                   |
| `/survival give <player> <item> <amount>`                         | Give items to another player in the survival arena.                            |
| `/rwf`                                                            | Show Search and Destroy command usage.                                         |
| `/rwf join`, `/rwf leave`                                         | Join or leave Search and Destroy.                                              |
| `/rwf kits`, `/rwf kit <name>`, `/rwf buy <kit>`                  | Browse, choose, or buy kits.                                                   |
| `/rwf rotation`, `/rwf vote <map>`, `/rwf time`                   | Check the rotation, vote, or check match time.                                 |
| `/rwf credits`, `/rwf who`, `/rwf stats [player]`                 | Check credits, players, or statistics.                                         |
| `/rwf teamchat`                                                   | Toggle team chat.                                                              |
| `/rwf spectate`, `/rwf spectate next`, `/rwf spectate previous`   | Spectate and switch players.                                                   |
| `/rwf goto <player>`                                              | Follow a player while spectating.                                              |
| `/rwf recording`                                                  | Check match recording status.                                                  |
| `/rwf killstreaks`, `/rwf killstreaks <first> <second> <third>`   | Open the killstreak picker or select three rewards.                            |
| `/rwf maps`, `/rwf vote`, `/rwf visit <map>`, `/rwf return`       | Browse the ballot, visit a candidate map, or return.                           |
| `/rwf size`, `/rwf options`, `/rwf settings`                      | Check match size, open match options, or view current and next-match settings. |
| `/rwf top [stat]`, `/rwf history`                                 | View leaderboards or match history.                                            |
| `/suicide`                                                        | Give up your life in an active Search and Destroy match.                       |

Survival commands require an active survival arena. Game commands can depend on your permissions and the current match state.

See [Mob Arena](/games/mob-arena/) and [Search and Destroy](/search-and-destroy/).
