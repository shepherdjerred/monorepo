---
title: Transparency
description: What the server shares with the community.
---

Transparency is a core goal of this server. As much as possible is shared
with the community, including [world downloads](../world_downloads/) and
[the code that makes the server tick](https://github.com/orgs/the-storm-mc/repositories).

Our hope is that this will empower the community, and ensure that players
always have access to their creations.
