---
title: Mail and Discord commands
description: Send mail and link your Discord account.
---

| Command                               | Action                                                        |
| ------------------------------------- | ------------------------------------------------------------- |
| `/mail`                               | Open your mail.                                               |
| `/mail claim <id> <option>`           | Claim a reward delivery using the choices shown in your mail. |
| `/discord link <code>`                | Complete account linking with a code from Discord.            |
| `/discord unlink`                     | Unlink your account.                                          |
| `/discord dms on`, `/discord dms off` | Change Discord DM notifications.                              |

For Discord-side commands and linking steps, see [Discord](/discord/) and [chat and mail](/community/chat-and-mail/).
