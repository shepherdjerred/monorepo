# Facet brand sources

These SVGs are the canonical source artwork for the Facet product identity.
The platform-specific PNG and ICNS files in the app targets are generated
artifacts; keep these originals unchanged when updating the native assets.

| Asset                       | Intended use                          |
| --------------------------- | ------------------------------------- |
| `icon-ios-1024.svg`         | iOS app icon source                   |
| `icon-macos-1024.svg`       | macOS app icon source                 |
| `icon-widget-512.svg`       | Widget and compact square icon source |
| `icon-notification-96.svg`  | Notification icon source              |
| `icon-menubar-template.svg` | macOS menu bar template source        |
| `icon-mono-line.svg`        | Monochrome and small-size mark source |
| `icon-favicon-32.svg`       | Favicon source                        |
| `wordmark-lockup.svg`       | Facet wordmark source                 |
| `hero-1600x600.svg`         | Brand hero artwork source             |
