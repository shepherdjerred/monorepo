---
title: Quest commands
description: Open and manage your quest journal.
---

| Command                   | Action                      |
| ------------------------- | --------------------------- |
| `/quests` (`/q`)          | Open your quest journal.    |
| `/quests track <quest>`   | Track a quest.              |
| `/quests abandon <quest>` | Abandon a quest.            |
| `/quests top`             | View the quest leaderboard. |

See [quests and NPCs](/adventures/quests-and-npcs/) and [quest progress](/adventures/quest-progress/).
