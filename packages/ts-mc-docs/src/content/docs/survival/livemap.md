---
title: LiveMap
description: Interactive browser map of the server's worlds.
---

Open the [LiveMap](https://bluemap.ts-mc.net/) to explore The Storm in your browser.

Use it to get your bearings, explore the shape of a world, or look for landmarks before a trip. Select a map from the map menu and zoom or move around to inspect the terrain. The map is a useful starting point, but check land in game with `/claim info` before you build.

Each [world](/survival/worlds/) has its own map:

| Map               | World                                               |
| ----------------- | --------------------------------------------------- |
| 2026 Map          | Frontier, the main survival world (the default map) |
| 2015 Map (/spawn) | Spawn, the restored Main Map 1                      |
| 2016 Map          | The restored Main Map 2                             |
| Skylands          | Floating islands                                    |
| Creative          | The creative plot world                             |
| Nether, The End   | The survival Nether and End                         |

A red line marks each world's border; turn it off under **World border** in the
map's marker menu. Minigame arenas are not on the map.

Explore the [creative map](https://bluemap.ts-mc.net/#creative), then visit the [creative guide](/creative/) to learn about plots.
