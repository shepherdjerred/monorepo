# rwfbots content

Repository-owned content for the Search and Destroy bots. The plugin reads it
at enable through `rwfbots.adapter.content.PersonalityFiles` and refuses to
start on any problem: an unknown key or value, a bad name, a blank skin, a
file whose name is not its `id`, a chat line that breaks the rules below, a
rival that does not exist, or two names players could confuse.

## `personalities/<id>.yml`

One file per bot persona. The file name is `<id>.yml`. Every key is required;
there are no defaults. Enum-like values are lower-case.

```yaml
id: ash-42 # [a-z0-9][a-z0-9-]{1,31}, unique, equals the file name
name: Ash_42 # [A-Za-z0-9_]{3,16}, not starting with ".", unique and
#   at least two edits from every other name (case-insensitive)
skin:
  value: "<Mojang texture property value, base64>"
  signature: "<Mojang texture property signature, base64>"
skill: 0.62 # 0..1, base skill before match shift
archetype: bomb_diver # the kind of player; the generator derives the knobs below from it
leverOffsets: # z-scores -3..3 by lever key; levers not listed sit on the curve
  reactionMs: 0.8 # positive is always stronger
  aimErrorDeg: -0.4
kits: # positive weights over the kits it picks from (at least one)
  trooper: 1
  longbow: 0.35
roles: # positive weights over the roles it prefers (at least one)
  plant: 1
  escort: 0.6
style: # each 0..1
  aggression: 0.7
  patience: 0.3
  teamplay: 0.55
  risk: 0.6
voice:
  tone: [dry, hype] # 1..4 distinct tags matching [a-z][a-z0-9-]{1,23}
  verbosity: normal # quiet | normal | chatty: how often it speaks
  style: all lowercase, 2014 gamer slang # 1..120 characters
lines: # match moments: 2..6 distinct lines; lobby: 4..8; each 1..80 characters
  greet: ["hi {team}", "lets go"]
  onKill: ["sit, {victim}", "next"]
  onDeath: ["gg {killer}", "lag"]
  onPlant: ["{bomb} is lit", "fuse in"]
  onDefuse: ["{bomb} is safe", "not today"]
  onWin: ["ez game", "gg"]
  onLoss: ["rematch", "gg"]
  onLastAlive: ["clutch time", "just me"]
  taunt: ["come get it", "too slow"]
  lobby:
    ["anyone trooper?", "gapples ready", "lets win this {team}", "brb water"]
quirks: [always_gg, loves_nuke] # 1..3 distinct
rivals: [ember-7] # 0..3 other personality ids
bio: Pushes first and asks questions later. # 1..3 sentences, at most 300 characters
batch: 1 # authoring batch number, from 1
retired: false # kept for history but never drafted when true
```

Archetypes: `rusher`, `lurker`, `sniper`, `bomb_diver`, `anchor`, `flanker`,
`support`, `duelist`, `hunter`, `turtle`, `troll`, `tactician`. The runtime
never reads the archetype; it reads the style, roles, kits and levers the
generator derived from it (see `scripts/bots/traits.ts`).

Placeholders, filled in by the chat layer: `{victim}` only in `onKill`,
`{killer}` only in `onDeath`, `{bomb}` only in `onPlant` and `onDefuse`, and
`{team}` (the speaker's team) in any moment. `lobby` is pre-match small talk,
kit talk and team pep while bots wait in the lobby, and may use only `{team}`. Any other `{` or `}` is an error.

Quirks: `always_gg`, `crouch_spam`, `never_eats`, `gapple_hoarder`,
`loves_nuke`, `late_to_everything`, `calls_everything`, `says_sorry`,
`blames_lag`, `holds_grudges`, `celebrates_early`, `bunny_hops`,
`bow_spammer`, `slow_starter`, `narrates`, `good_sport`, `stares_down`,
`spins`. Nothing acts on them yet.

Lever keys: `reactionMs`, `aimErrorDeg`, `turnRateDegPerTick`, `cps`,
`predictionQuality`, `decisionTemperature`, `awarenessRadius`,
`coordination`, `technique`, `aggression`.

Kits: `trooper`, `longbow`, `shortbow`, `rewind`, `ghost`, `wraith`, `spy`.
Bots are handed only the kits in `rwfbots.yml` `draft.kits`; a personality
whose weights name none of those still drafts and plays one of them.

Roles: `plant`, `escort`, `defend`, `rotate`, `retake`, `hunt`.

The shape is defined by `PersonalityFile` in the plugin and mirrored by the
zod schema in `packages/the-storm/scripts/bots/schema.ts`; change both
together. Files are generated by `bun run bots:generate` from
`packages/the-storm` (see `scripts/bots/README.md`), never hand-edited: the
text comes from the reviewed enrichment files in `scripts/bots/enrichment/`.
`manifest.json` records every batch (seed, count, generator version), the
enrichment files used, and each personality's batch, archetype and skin
provenance. `ShippedPersonalitiesTest` parses this directory on every build.
