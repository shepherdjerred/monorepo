Every number on this page is imported from the constant the bot runs on, so it
cannot drift from the implementation. `/bb rules` in Discord states the same
rules from the same constants.

Bryan Bucks have no cash value. Nothing can be redeemed, and `/bb prizes` is a
joke catalogue.

## Windows

| Market        | Open for                                                                                                                                                        |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Outcome       | {Math.floor(BETTING_WINDOW_MS / 60_000)} minutes from detection                                                                                                 |
| Match parlay  | {Math.floor(PARLAY_BETTING_WINDOW_MS / 60_000)} minutes from publication                                                                                        |
| Weekly parlay | Sunday {weeklyParlayWallClockLabel(WEEKLY_PARLAY_OPEN_HOUR)} to Monday {weeklyParlayWallClockLabel(WEEKLY_PARLAY_BETTING_CLOSE_HOUR)}, {WEEKLY_PARLAY_TIMEZONE} |

The outcome window runs from when Scout _detected_ the game, not from when the
game started, and it is clamped against the game's own start time so a late
detection cannot silently extend it.

A market that never receives a result is voided and fully refunded after{" "}
{VOID_GRACE_MS / 3_600_000} hours.

## Weekly parlays

A weekly parlay scores eligible completed games from Monday{" "}
{weeklyParlayWallClockLabel(WEEKLY_PARLAY_BETTING_CLOSE_HOUR)} through Sunday{" "}
{weeklyParlayWallClockLabel(WEEKLY_PARLAY_FINAL_HOUR)}, using a half-open window
in {WEEKLY_PARLAY_TIMEZONE}. Scout posts {WEEKLY_PARLAY_UPDATE_COUNT} progress
updates at {weeklyParlayWallClockLabel(WEEKLY_PARLAY_UPDATE_HOUR)} and may settle
YES early only after every leg is permanently satisfied. NO always waits for
final settlement, which begins {WEEKLY_PARLAY_INGESTION_GRACE_MINUTES} minutes
after the scoring cutoff so a completed game has two worst-case polling
intervals to ingest.

Scout selects a linked active player with at least {WEEKLY_PARLAY_MIN_RECENT_GAMES}
eligible games, at least {WEEKLY_PARLAY_MIN_HISTORY_WINDOWS} fully observed
weekly windows among the trailing {WEEKLY_PARLAY_HISTORY_WINDOW_COUNT}, and no
feature during the previous {WEEKLY_PARLAY_FEATURE_COOLDOWN_PERIODS} periods.
The market has {WEEKLY_PARLAY_MIN_LEGS}–{WEEKLY_PARLAY_MAX_LEGS} legs and is
published only when replaying aligned historical weeks measures a YES rate
between {WEEKLY_PARLAY_MIN_YES_PROBABILITY_BPS / 100}% and{" "}
{WEEKLY_PARLAY_MAX_YES_PROBABILITY_BPS / 100}%. If no candidate clears every
gate, Scout publishes no weekly parlay.

If the standard Sunday opening is missed, an operator may start a catch-up
market for that period. Betting remains open for at least{" "}
{WEEKLY_PARLAY_CATCHUP_MINIMUM_BETTING_HOURS} hours before scoring starts at a
Pacific midnight. The market message shows the frozen betting and scoring
timestamps. Games completed before betting closes do not count.

## Stakes

| Limit                | Value                            |
| -------------------- | -------------------------------- |
| Minimum stake        | {MIN_STAKE} BB                   |
| Button denominations | {BUTTON_STAKES.join(" BB, ")} BB |
| Maximum stake        | Your balance                     |
| New wallet grant     | {SEED_GRANT} BB                  |

There is no product cap on a bet beyond what your wallet can cover. The grant
for a new wallet is transferred from the house bankroll, not created.

## Fees

| Event                          | Fee                                                              |
| ------------------------------ | ---------------------------------------------------------------- |
| Placing a bet                  | none                                                             |
| Unmatched BB refunded at close | none                                                             |
| Outcome winner                 | {HOUSE_CUT_PERCENT}% of matched **profit**, rounded down         |
| Cancelling an outcome bet      | {HOUSE_CUT_PERCENT}% of the **offer**, rounded to the nearest BB |
| Cancelling a parlay            | none                                                             |
| Any void or remake refund      | none                                                             |

The two {HOUSE_CUT_PERCENT}% figures use different bases and different
rounding, and that is deliberate: the winner fee rounds down so a winning 1 BB
match still profits.

## Matching

| Rule                  | Value                                                  |
| --------------------- | ------------------------------------------------------ |
| Human offers match    | first, at even money                                   |
| Oversubscribed offers | matched proportionally                                 |
| House fill per game   | up to {HOUSE_MATCH_LIMIT} BB, aggregate                |
| House bankroll        | {HOUSE_BANKROLL.toLocaleString("en-US")} BB per server |
| Winner receives       | 2× matched stake, less the winner fee                  |

The house fill is capped **for the whole game**, not per player. See
[why bets use matched stakes](/docs/explanation/bryan-bucks-matched-stakes/).

League Classic is a special case: it awards a participation point but carries
**no market**, because Riot exposes no post-game payload for it and a market
that cannot be settled reliably should not be opened. ARAM and Arena are not
eligible at all.

A game shorter than {REMAKE_MAX_DURATION_SECONDS / 60} minutes is treated as a
remake: no Bucks are earned and every stake is refunded.

## Earnings

Earned on an eligible completed game, per linked tracked player:

| Reason                       | Award                        |
| ---------------------------- | ---------------------------- |
| Played                       | +1 BB                        |
| Won                          | +1 BB                        |
| MVP                          | +1 BB                        |
| Ranked 5s bonus              | +1 BB                        |
| Clash bonus                  | +10 BB                       |
| League Classic participation | +1 BB (pre-match, no market) |

## Peek passes

A pass lasts 24 hours and covers unlimited peeks. Its price scales with your
balance and how long you have held it, with a floor. A peek becomes available
a short time after the game goes live and disappears once the market resolves.

`/bb rules` in Discord states the floor and the delay exactly.
