---
title: Build Stargates
description: Build two sign-and-button portals on a network.
---

Build two Stargates on the same network to connect destinations. You need Mechanic III, access to the network, and permission to build across the whole gate.

1. [Create or join a network](/progression/stargate-networks/).
2. Build an obsidian frame with two blocks across the top and bottom and three blocks high on each side. Leave the two-wide, three-high opening empty.
3. Place a wall button on one middle side block. Place a wall sign on the opposite middle side block, facing the same direction as the button.
4. Write the gate name on sign line 1 and the network name on line 3. Wait for the `Stargate <name> created.` message to confirm it was saved.
5. Build a second gate with a different name on the same network. Right-click the first sign to cycle to it, press the button, and walk into the open portal.

For example, create a public network named `HomeRoad`, then build gates named `Home` and `Mine` with `HomeRoad` on line 3 of each sign. Select `Mine` at Home to travel there, and select `Home` at Mine to return.

Use `/stargate remove <network> <gate>` when authorized to remove a registered gate. Remove it before changing its blocks or sign. If travel fails, check your network access, the frame and the destination.
