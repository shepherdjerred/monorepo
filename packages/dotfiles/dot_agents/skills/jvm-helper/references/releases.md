# JVM ecosystem release lifecycle

Read this when upgrading Java, Kotlin, Gradle, Maven, JUnit, or a major framework.

## Current status

JDK 26 is current GA. Java 25 is Oracle's latest designated LTS, but support policy is vendor-specific. Kotlin 2.4.10, Gradle 9.6.1, Maven 3.9.16, and JUnit 6.1.2 were current on 2026-08-03.

Current does not mean compatible with every project. JUnit 6 and Spring Boot 4 are major migrations. Preview Java APIs can change each feature release and require compile/run preview flags.
