Community challenges turn a plain-language goal into a fixed, measurable
contract that Scout evaluates from the matches it already records.

## Draft the challenge in Explore

Open **Explore** and describe the goal. Be explicit about observable match
facts, such as wins, champions, roles, queues, streaks, or a statistic Scout
stores.

Scout returns:

- canonical rules,
- a plain-language explanation,
- a preview against known history, and
- any evidence it cannot evaluate, such as missing timelines.

Subjective goals are rejected. Scout can measure "win with every champion," but
not "win while playing stylishly."

Review the frozen contract and explicitly confirm publication. Publishing makes
that version available immediately to every signed-in Scout user. Editing a
published challenge creates a new version; runs already in progress keep the
version they started with.

## Start a run

Open **Challenges**, choose a template, and select the linked Riot accounts
that should contribute. You can start in either mode:

- **Clean slate** counts eligible matches from now onward.
- **Import history** counts all Scout-known eligible matches since a date you
  choose. Use **Earliest known** to include everything Scout retained.

An import can complete the run immediately. The coverage panel always shows the
selected period, evaluated match count, and missing timeline evidence, so a
partial history never looks complete by implication.

The built-in **Win on every current champion A–Z** challenge freezes the current
champion list when you start. A champion released later does not move that
run's finish line.

## Change contributing accounts

Open the run and change the selected linked accounts. Scout creates a new
evaluation revision and recomputes from the run's original start date.

While that work runs, the page keeps showing the last complete snapshot with a
**Recomputing** marker. Scout replaces it atomically only after the new revision
is complete.

## Restart or run something else

You may run different challenge templates at the same time. You may have only
one active run of a particular template.

Restarting archives the previous run and starts a new one. Choose clean slate
when the point is a genuinely new attempt; choose an import when you want Scout
to reconstruct progress from retained evidence.

Runs also appear on every guild player profile linked to the owner's Discord
identity. Other current members of one of those guilds may open the run, while
the account selections remain governed by Scout's normal access rules.
