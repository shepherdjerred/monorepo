Use Seerr's Advanced Requests tags when a new TV request should receive original Simplified Chinese subtitle searches.

1. Find the TV series in Seerr and choose **Request**.
2. Open **Advanced Requests**.
3. Under **Tags**, select **chinese**.
4. Submit the request.

Sonarr applies the tag to the series. Bazarr maps it to the Simplified Chinese profile and searches its approved subtitle sources. A request without that tag uses the normal subtitle profile.
