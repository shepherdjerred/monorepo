export const textKinds = REPORT_RENDER_KINDS.filter((kind) => !kind.isChart);
export const chartKinds = REPORT_RENDER_KINDS.filter((kind) => kind.isChart);

The trailing `RENDER <kind> [WITH (...)]` clause decides how a report is
displayed. A query with no `RENDER` clause renders as a table.

ranked player rows by default; change that with the `mentions` option below.

## Which options a kind needs

| Kind                       | Typically needs                                    |
| -------------------------- | -------------------------------------------------- |
| `bar_chart`, `stacked_bar` | `y`, optionally `orientation`                      |
| `line_chart`, `area_chart` | `y`, a time dimension in `GROUP BY`                |
| `donut_chart`              | `y`, few rows                                      |
| `scatter_chart`            | `x`, `y`, optionally `size`                        |
| `heatmap`                  | `value`, `series`, two grouping dimensions         |
| `radar_chart`              | `y` with three to eight series                     |
| `kpi_card`                 | `y` (one or more), and `GROUP BY all`              |
| `bump_chart`               | `y`, and an `ANALYZE` clause                       |
| `calendar_heatmap`         | `y` (exactly one), `GROUP BY all`, `BUCKET BY DAY` |
| `leaderboard`              | optionally `mentions`                              |

A name used in `WITH` must be one of the query's own outputs. Referring to a
column the `SELECT` does not produce is the most common cause of an empty or
malformed chart.
