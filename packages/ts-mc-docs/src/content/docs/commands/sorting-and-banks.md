---
title: Sorting and banks commands
description: Sort items and find deposit banks.
---

| Command                                                            | Action                                                                                                                                               |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/sort` (`/chestsort`, `/isort`)                                   | Show sorting settings. The aliases also work with the subcommands below.                                                                             |
| `/sort on`, `/sort off`, `/sort toggle`                            | Change automatic sorting.                                                                                                                            |
| `/sort inventory`, `/sort hotbar`, `/sort all`                     | Sort the chosen part of your inventory.                                                                                                              |
| `/sort hotkeys`                                                    | Show sorting hotkeys.                                                                                                                                |
| `/bank` (`/mondo`), `/bank list`, `/bank find <item>`              | Show bank information, list access to the bank you are looking at, or find an item. The alias also works with the subcommands below.                 |
| `/bank add`, `/bank quit`                                          | Link the container you are looking at as a shelf, or remove your own access to the bank you are looking at.                                          |
| `/bank access add <player> [role]`, `/bank access remove <player>` | Manage access to the bank you are looking at, if you have management access. Roles are `open`, `add`, `remove`, and `manage`; the default is `open`. |

See [sorting](/everyday/sorting/) and [deposit banks](/everyday/deposit-banks/).
