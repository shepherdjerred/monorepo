# Match review map

`summoners-rift-16.18.1.png` is Riot's Data Dragon minimap, pinned to 16.18.1:
https://ddragon.leagueoflegends.com/cdn/16.18.1/img/map/map11.png

The shared asset plugin serves and copies this image. Match review uses it only
for modern Summoner's Rift (map 11); positions are recorded snapshots, not a
reconstruction of vision, movement, or patch-specific terrain changes.
