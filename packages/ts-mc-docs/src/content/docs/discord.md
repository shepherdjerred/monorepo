The Storm's Discord has a channel linked to the server while it is awake. Chat
there reaches Global chat in game, and the game posts back to it.

## What gets posted

- Global chat, joins, leaves, deaths and advancements.
- Search and Destroy and Mob Arena lobbies as they open, and their results:
  the winning team, how far an arena run got, and new arena records.
- Mob Arena boss waves that pay rewards.
- New towns, and towns reaching 25, 50, 100 and 200 claimed chunks.
- Story and questline completions, and skills reaching each hundredth level.
- Seasonal events that are running when the server wakes up.

Players who are vanished are never named. The bot's status shows how many
people are online and which games are running.

## Commands

Use these in the linked channel. Answers other than `/list` and `/status` are
only shown to you.

| Command                        | What it does                                     |
| ------------------------------ | ------------------------------------------------ |
| `/list`                        | Who is online                                    |
| `/status`                      | Who is online and which games are running        |
| `/baltop`                      | The richest players                              |
| `/towns [page] [name]`         | Towns, spawn and historic sites                  |
| `/arena-top [arena]`           | Best Mob Arena waves                             |
| `/rwf-stats <player>`          | A player's Search and Destroy record             |
| `/link` and `/unlink`          | Link or unlink your Discord account              |
| `/ticket <category> <summary>` | Report a problem to staff (linked accounts only) |
| `/mail <player> <text>`        | Send an in-game letter (linked accounts only)    |

## Linking your account

1. Use `/link` in the Discord. It gives you a six-character code that lasts ten
   minutes.
2. In game, type `/discord link <code>`.

Once linked, you can file tickets and send letters from Discord. They count as
coming from your player and follow the same rules as in game; you can file a
ticket every two minutes and send a letter every thirty seconds.

`/discord dms on` sends you your own Search and Destroy and Mob
Arena results by direct message, and `/discord dms off` stops them. Use
`/discord unlink` in game or `/unlink` in Discord to remove the link.
