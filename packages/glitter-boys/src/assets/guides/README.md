# Guide screenshots

These assets illustrate the Windows walkthroughs and Apple silicon macOS setup page. Website captures
and recording frames were prepared on 7 October 2026. They do not establish a
locally tested game installation or multiplayer session.

For original application captures, keep the visible client/game version and
capture date in the guide's verification notes. Use a plain `sourceName` credit
such as `Glitter Boys, captured 9 October 2026` without `sourceHref`; retain
external source links for upstream examples. Record only the installation and
gameplay checkpoints actually reached. Crop private information from published
captures and preserve the displayed controls and results.

## Launcher captures

`launcher-library.png` is an original capture of Glitter Boys Launcher 0.1.0 on
Windows, taken October 9, 2026. It shows the real preview interface, not a mockup.
It does not establish successful installation or multiplayer gameplay.

`launcher-installed.jpg` is an original October 9, 2026 capture of the compact
Windows preview with all four local installations ready. All controls fit in its
900 by 640 logical-pixel client area. This proves visible local installation
state, not successful multiplayer gameplay.
