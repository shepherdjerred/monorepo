Starlight Karma Bot is a Discord bot that manages karma points, leaderboards, and history commands for servers. It runs on Bun with discord.js v14, Prisma backed by SQLite through the libSQL adapter, dotenv/env-var configuration helpers, and Sentry instrumentation declared in `package.json:1`. The data layer is defined in `prisma/schema.prisma:1` with the client constructed in `src/db/index.ts:1`; aggregate reads use Prisma `groupBy`/`aggregate` in `src/karma/queries.ts:1`, and the legacy TypeORM database is imported once on first boot by `src/db/import-legacy.ts:1`.
