# Zellij release lifecycle

Read this when upgrading Zellij, adopting 0.44 automation/web features, or checking plugin/session compatibility.

## Current version

Zellij 0.44.3 is current as of 2026-08-03. The 0.44 line introduced a protocol-buffer client/server contract for forward-compatible sessions after the transition. Read each patch release before scripting newly added actions.
