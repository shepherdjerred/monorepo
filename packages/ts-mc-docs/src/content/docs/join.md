---
title: How to join The Storm
description: Connect to The Storm from Minecraft Java or Bedrock Edition.
---

Join The Storm from Minecraft Java or Bedrock Edition. A forum account is not required to play.

## Java Edition

1. Open Minecraft **Java Edition 26.2** with your Microsoft account.
2. Choose **Multiplayer**, then **Add Server**.
3. Name the server **The Storm** and enter **`ts-mc.net`** as the address.
4. Save it, select The Storm, and choose **Join Server**.

Java discovers the port automatically. If your client cannot resolve the address, enter **`mc.ts-mc.net:30000`** instead.

## Bedrock Edition

1. Open Minecraft **Bedrock Edition** and sign in to your Microsoft account.
2. Open **Play**, then **Servers**, then **Add Server**.
3. Name the server **The Storm**.
4. Enter **`mc.ts-mc.net`** as the address and **`30004`** as the port, in separate fields.
5. Save the server and join.

Use the supported Bedrock version shown on [the homepage](https://ts-mc.net/). Bedrock compatibility can differ from the Java version.

Some console editions do not offer **Add Server**. These steps apply to devices that allow custom server addresses.

## If you cannot connect

- Check [the homepage](https://ts-mc.net/) for Java and Bedrock status separately. During maintenance, wait for your edition to become available.
- On Bedrock, check that the address is `mc.ts-mc.net` and the separate port is `30004`.
- On Java, try the manual address above and verify that your game is version 26.2.
- If the problem continues, ask in [Discord](/discord/) and include your edition, game version, and error message.

## Once you arrive

You start at the windmill with supplies, a welcome book, and 500 crystals. Open `/guide` for your first steps, or follow [your first session](/getting-started/).
