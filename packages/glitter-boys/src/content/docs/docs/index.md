On **Windows x64**, start with the [Glitter Boys launcher guide](/docs/launcher/).
The launcher installs MW2, Black Ops, Black Ops II, and Black Ops III, then opens
the right client when you choose Play. It is currently an unsigned preview
available directly from Jerred; a public signed release is not available yet.

## Mac + Windows crossplay

Choose your platform before installing:

The launcher is for Windows. Mac setup stays separate, and a mixed Mac/Windows
session has not yet been verified here. Read the
[compatibility reference](/docs/crossplay/) before choosing a client, especially
for BO3: the BOIII launcher route differs from the Steam + T7Patch crossplay route.

- [Windows setup](/docs/crossplay/windows/)
- [macOS setup (Apple silicon)](/docs/crossplay/macos/)
- [Play together](/docs/crossplay/play-together/) once both players are set up

Use these walkthroughs when setting up a client by hand, troubleshooting, or

Each walkthrough includes downloads, extraction, client setup, screenshots you
can enlarge, and steps for playing together. Start at step 1 for a fresh install,
or use the page's contents list to jump to client setup for an existing game.
For an existing Steam installation, use **Manage → Browse local files** to find
the game folder.

## Before you start

- Allow enough free space for both the downloaded archive and the extracted game.
- Extract the game into its own folder, such as `C:\Games\`, rather than running it inside the ZIP.
- Everyone should use the same current client and have the map they want to play.
- Keep the client launcher: use it to get updates before the next session.
