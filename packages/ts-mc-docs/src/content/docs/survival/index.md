Make a home, found a town, and build your place in The Storm. Earn crystals through quests and trading, and use Storm Shards to improve your equipment.

New here? [Your first session](/getting-started/) takes you from the windmill to a claimed base and a saved home. Read [the rules](/norms/) before heading out: PvP is enabled by default, and unlocked containers are fair game where access permits.

- [LiveMap](./livemap/): explore the worlds from your browser.
- [Worlds](./worlds/): world borders and dimensions.
- [Transparency](./transparency/): what the server shares with the
  community.
