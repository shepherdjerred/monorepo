# Proof of Concept

Experiments that may or may not go anywhere. Not shipped, excluded from most lint/CI.

- [hkctl](hkctl/) — minimal Apple HomeKit CLI via `HMHomeManager` (Mac Catalyst)
- [interview-practice](interview-practice/) — AI coding-interview practice CLI that simulates a realistic interviewer
- [sentinel](sentinel/) — autonomous agent system for operational tasks (CI fixing, health checks, alert triage) with human approval gates
