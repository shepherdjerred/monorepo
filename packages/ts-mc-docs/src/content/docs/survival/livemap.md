title: LiveMap
description: Interactive browser map of the server's worlds.
---

The [LiveMap](https://bluemap.ts-mc.net/) is a web-based tool that shows
an interactive map of the worlds on the server. It can best be described
as Google Maps for Minecraft.

Survival is the default map. The creative plot world is the map named creative
on the same site, beside survival: [creative](https://bluemap.ts-mc.net/#creative).
How to enter, claim, name, trust, and download a plot is on the
[creative](/creative/) page.
