---
title: Travel commands
description: Homes, teleports, and world travel.
---

| Command                                            | Action                                                                               |
| -------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `/worlds`                                          | List worlds.                                                                         |
| `/rtp [world or biome]`, `/rtp <world> <biome>`    | Travel to a random location, optionally in a world or biome.                         |
| `/spawn`, `/back`                                  | Travel to spawn or your previous location.                                           |
| `/sethome [name]`, `/home [name]`                  | Save a home or travel to one.                                                        |
| `/homes`, `/delhome <name>`                        | List or delete saved homes.                                                          |
| `/warp [name]`                                     | List warps or travel to one.                                                         |
| `/tpa [player]`, `/tpahere [player]`               | Request travel to a player or ask them to come to you; without a player, show usage. |
| `/tpaccept [player] [id]`, `/tpdeny [player] [id]` | Respond to a teleport request. An ID requires a player.                              |
| `/tptoggle`, `/tpinfo [category]`                  | Toggle requests or check teleport details and costs.                                 |

See [travel](/survival/travel/) and [teleport requests](/survival/advanced/teleport-requests/).
