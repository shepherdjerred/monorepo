# Game icons

These PNGs preserve the game icons extracted at 256 × 256 from the locally
installed Windows executables. They identify the games in the launcher and are
embedded at build time; no game installation or network request is needed to
display them.

| Asset     | Executable resource                  | Game                                                            |
| --------- | ------------------------------------ | --------------------------------------------------------------- |
| `mw2.png` | `iw4sp.exe`                          | [Modern Warfare 2 (2009)](https://steamcommunity.com/app/10180) |
| `bo1.png` | `t5sp.exe` from the Plutonium client | [Black Ops](https://steamcommunity.com/app/42700)               |
| `bo2.png` | `t6mp.exe` from the Plutonium client | [Black Ops II](https://steamcommunity.com/app/202970)           |
| `bo3.png` | `BlackOps3.exe`                      | [Black Ops III](https://steamcommunity.com/app/311210)          |
