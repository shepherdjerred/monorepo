---
title: Chat and settings commands
description: Choose channels and manage messages.
---

| Command                                                               | Action                                                              |
| --------------------------------------------------------------------- | ------------------------------------------------------------------- |
| `/channels`                                                           | List chat channels.                                                 |
| `/channels hide <channel>`, `/channels show <channel>`                | Hide or show a channel.                                             |
| `/g [message]`, `/war [message]` (`/wc`), `/tc [message]`             | Switch to global, war, or town chat, or send one message there.     |
| `/t <message>`, `/dead <message>`                                     | Send a message to team or dead chat; without a message, show usage. |
| `/me <message>`                                                       | Send an action in your channel.                                     |
| `/msg <player> <message>` (`/tell`, `/whisper`, `/w`), `/r <message>` | Send or reply to a private message.                                 |
| `/ignore [player]`, `/unignore <player>`                              | List ignored players, ignore a player, or restore their chat.       |
| `/afk`                                                                | Toggle your away status.                                            |

See [chat and mail](/community/chat-and-mail/).
